# Voucher Hub

## Vision

Voucher Hub is a mobile application that helps users manage, use, sell, and discover vouchers, gift cards, store credits, and referral codes.

The goal is to prevent value from being lost through forgotten, expired, or unwanted vouchers.

Voucher Hub turns vouchers into a manageable digital asset rather than a piece of paper that eventually gets lost or expires.

---

## Problem

Millions of dollars in voucher value are lost every year because users:

- Forget they own a voucher
- Lose the physical voucher
- Cannot find the voucher when they need it
- Forget expiration dates
- Receive vouchers for brands they do not like
- Receive vouchers they will never use
- Would rather have cash than store credit

Example:

A user receives a €100 gift card for a clothing store as a birthday gift.

The user:
- Does not shop at that store
- Has no intention of using the gift card
- Would prefer €80 in cash

Today there is no simple solution.

Voucher Hub solves this by helping users:
- Store vouchers
- Track vouchers
- Use vouchers
- Sell unwanted vouchers
- Buy discounted vouchers from others

---

## Core Pillars

### 1. Personal Voucher Wallet

Manage all vouchers in one place.

### 2. Voucher Marketplace (resale)

Convert unwanted vouchers into cash.

### 3. Referral Code Hub

Discover and share referral codes.

---

## Target Users

### Primary Users

- Frequent shoppers

### Secondary Users

- Bargain hunters
- Referral code users

## Main Value Proposition

Never lose a voucher again.

And if you don't want it, sell it.

---

## Main KPI

Total voucher value saved from expiration.

Secondary KPI:

Total voucher value exchanged through the marketplace.

---

## Long-Term Goal

Become the central platform for vouchers, gift cards, store credits, referral codes, and consumer rewards.
