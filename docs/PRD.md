# Product Requirements Document

## User Problem

Users regularly receive vouchers and gift cards.

Common issues:

### Problem 1: Forgotten vouchers

Users forget vouchers exist.

Result:

- Voucher expires
- Money is lost

### Problem 2: Lost vouchers

Users cannot find the voucher when needed.

Result:

- Voucher remains unused

### Problem 3: Unwanted vouchers

Users receive vouchers for:

- Stores they do not shop at
- Restaurants they do not visit
- Brands they do not like
- 

Result:

- Voucher never gets used

### Problem 4: Cash preference

Many users would rather receive cash than store credit.

Example:

Voucher value: €100

User would happily sell it for: €80

Buyer receives a discount.

Seller receives cash.

Both parties benefit.

## Problem 5: No access/overview to referral codes of friends
Many users want to use a referral code but don't know who offers them
You as a user have a referral code but your firneds don't use then, you don't want to push them to use your referral code, because then it seems fro your own benefit.

Result: When the referral code is needed, you can't match supply and demand.

### Problem 6: Purchase of gift cards is decentralised
If a user wants to buy a gift card, there is no central marketplace wheren they can search for the best fit brand and purchase it at a cental shop.

---

## Solution

Voucher Hub provides:

1. Voucher storage
2. Voucher reminders
3. Voucher marketplace (resale and new)
4. Referral code hub

# Functional Requirements

## Authentication

Users can:

- Register
- Login
- Logout
- Reset password

---

## Voucher Management

Users can:

- Add voucher
- Edit voucher
- Delete voucher
- Search voucher
- Mark voucher as used
- Mark voucher as sold

---

## Voucher Information

Each voucher contains:

- Brand
- Voucher Value
- Currency
- Expiration Date
- Voucher Code
- PIN
- Notes
- Image

---

## Notifications

Users receive reminders before expiration.

Default reminders:

- 30 days
- 7 days
- 1 day

---

## Marketplace

Users can:

- List vouchers
- Set selling price
- Browse listings
- Search by brand
- Search by category

---

## Referral Codes

Users can:

- Add referral codes
- Search referral codes
- Copy referral codes
