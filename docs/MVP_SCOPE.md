# MVP Scope

> **Status: historical.** This describes the original MVP cut, kept for
> context. Several items listed under "Excluded" below have since shipped
> (AI extraction, OCR voucher scanning, the friend system, friends-only
> visibility) — see `docs/DATABASE_SCHEMA.md` and the code for current
> scope. Don't treat this page as a gate on what's allowed to exist.

## Goal

Validate that users want a central place to manage vouchers and referral codes.

---

## Included

### Authentication

- Email signup
- Email login

### Voucher Wallet

- Add voucher manually
- Edit voucher
- Delete voucher
- Search vouchers
- Expiration reminders

### Referral Code Hub

- Add referral code
- Search referral code
- Copy referral code

### Basic Marketplace

- List voucher for sale
- Browse vouchers
- View voucher details

---

## Excluded

### Payments

No payment processing.

### Escrow

Not included.

### Ratings

Not included.

### AI Extraction

Not included.

### OCR

Not included.

### Friend System

Not included.

### Social Feed

Not included.

### Fraud Detection

Not included.

---

## Success Criteria

Users can:

1. Store vouchers
2. Find vouchers
3. Receive reminders
4. Sell unwanted vouchers
5. Discover referral codes
